# Model Change Lists

Public, per-release lists of which closed models were added, re-characterized, unchanged or retired, and why. See "Model Change Lists" in `VERSIONING.md`.

Columns: `status` is new, re-characterized, unchanged or retired. Confidence bands are low, medium or high. `energy_per_request_direction` is up or down; `energy_per_request_change_band` is under 5%, 5-20%, 20-50% or over 50%.

These files never contain per-token factors, exact percentage changes or exact confidence scores. Those are in the licensed factor diff delivered with each factor release.

Remove the EXAMPLE rows before release.
